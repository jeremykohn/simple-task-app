# Simple Task App

This repository is a minimal starter for the Simple Task App. It currently
contains only basic scaffolding so contributors and AI agents can make
incremental, discoverable changes.

## Run / test

- Install dependencies (none required yet):

```bash
cd <path-to-this-repo>
npm ci
```

- Run the app (starts a tiny HTTP server on `PORT` 3000 by default):

```bash
npm start
# or explicitly:
node index.js
```

- Run tests (placeholder):

```bash
npm test
```

## Notes for contributors and AI agents

- Prefer non-destructive changes: add `README.md`, small example files, or
  minimal manifests before larger refactors.
